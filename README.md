# Case Summary Dashboard

De-identified PharmSim cross-case dashboard for instructor review.

## Contents

- `index.html`: dashboard page
- `app.js`: dashboard logic
- `styles.css`: dashboard styling
- `data.js`: bundled de-identified dashboard data

## Notes

- The dashboard is static and can be opened directly from `index.html`.
- Student records are de-identified with anonymous IDs.
- Score-change views are descriptive and should not be interpreted as causal learning progress.
- Performance summaries include only completed simulations with available evaluation/rubric data.
